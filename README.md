# js-rock-paper-scissors

`Rock paper scissors is a hand game played between two players, where one player is human (on the left) and the other is the computer. Each player simultaneously forms one of three shapes: rock (a fist), paper (a flat hand), or scissors (a fist with the index and middle fingers extended). The game has three possible outcomes: rock crushes scissors, scissors cuts paper, and paper covers rock, with ties resulting in a replay.`
